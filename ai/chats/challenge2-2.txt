5. Improve terminal table alignment
-----------------------------------

Request:
"The cli output is not consistently aligned. Ensure it is and add a test"

Updated terminal rendering to calculate display widths using Unicode
character categories and East Asian width, rather than Python string length.
Combining marks do not consume display columns; wide and full-width
characters consume two. Tabs, carriage returns, and other control characters
are escaped visibly so they cannot disrupt the table layout. Newlines in
cells are rendered as " / ".

Added a regression test with wide CJK characters and a tab, asserting the
exact aligned output. An initial test expected the wrong amount of padding;
the expectation was corrected after running the suite.

Verification:
All 17 unit tests passed.


6. Require .md extension for output files
-----------------------------------------

Request:
"Output mnust be a markdown file. Treat the input after -o as the filename
and always append a .md file extension unless the user has entered a .md file
extension"

The output name now receives a ".md" suffix unless its suffix is already
".md", compared case-insensitively. Thus "-o report" writes report.md,
"-o report.txt" writes report.txt.md, and "-o report.MD" remains report.MD.
Added tests for these cases.
